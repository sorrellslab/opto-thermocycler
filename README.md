## Overview
Design files and code for running the opto-thermocycler behavior assay that measures mosquito responses to optogenetic stimulation and heat 

## Repository Structure
```text
├── Arduino/optothermo_lightheat/     # Arduino code for stimulis delivery
├── Laser_cutter_templates/           # Schematic for making acrylic plate - thick is for 0.125 inch acrylic and thin is for 0.0625 inch acrylic
├── OTC_thermocycler_programs/        # Thermocycler programs for stimulis delivery
├── models/                           # Sleap models for predicting on OTC videos
